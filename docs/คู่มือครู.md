# คู่มือครู: Word Arena

เกมทายคำศัพท์สดในห้องเรียนสำหรับนักเรียนสูงสุด 200 คน รอบละ 3 นาที มีสองเกม คือ Guess the Word (ทายคำจากความหมายที่ใกล้เคียง) และ Davini (ถอดรหัส แล้วดูอิโมจิ แล้วตอบคำ)

ระบบมีสองส่วน
- **หน้าเว็บ** อยู่บน GitHub Pages นักเรียนและครูเปิดผ่านเบราว์เซอร์
- **server เกม** อยู่บน Cloudflare Workers (แผนฟรี) ทำหน้าที่รับคำทาย ตรวจคำตอบ และนับคะแนน

ทั้งสองส่วน deploy อัตโนมัติทุกครั้งที่ครู push ขึ้น GitHub แต่ต้องตั้งค่าครั้งแรกตามขั้นตอนด้านล่าง ใช้เวลาประมาณ 20–30 นาที

> หมายเหตุ: ชื่อเมนูของ Cloudflare ในคู่มือนี้ตรวจกับเอกสารทางการของ Cloudflare เมื่อ 27 พ.ย. 2569 แต่ผู้เขียนยังไม่ได้เปิดหน้าจอจริงดู ชื่อปุ่มบางจุดจึงอาจต่างไปเล็กน้อย จุดที่ไม่แน่ใจมีหมายเหตุกำกับไว้

## ส่วนที่ 1 ตั้งค่าครั้งแรก

### 1.1 นำโค้ดขึ้น GitHub
1. สร้าง repository ใหม่บน GitHub เช่น `word-arena` จะตั้งเป็น Public หรือ Private ก็ได้ แต่ถ้าเป็นบัญชีฟรี GitHub Pages ใช้ได้กับ repo แบบ Public เท่านั้น
2. เปิด GitHub Desktop แล้วเลือก **Add an Existing Repository** ชี้ไปที่โฟลเดอร์ `word-arena`
3. กด **Publish repository**

### 1.2 สมัคร Cloudflare และสร้าง API token
1. สมัครบัญชีฟรีที่ cloudflare.com
2. ไปที่หน้า **Account API tokens** แล้วกด **Create Token**
3. ในส่วน Permission policies เลือก **Edit Cloudflare Workers**
4. ตั้งชื่อ token เช่น `word-arena-deploy` และจำกัดสิทธิ์ไว้ที่บัญชีของครูบัญชีเดียว
5. กดสร้าง แล้ว**คัดลอก token เก็บไว้ทันที** เพราะ Cloudflare แสดง token ให้ดูครั้งเดียว
6. หา **Account ID** ของครู (มักอยู่ในหน้าภาพรวมของบัญชี หรือหน้า Workers & Pages — *ผู้เขียนยังไม่ได้ตรวจตำแหน่งบนหน้าจอจริง*)

**ห้ามนำ token ไปวางในไฟล์ใดใน repo** ให้ใส่ในข้อ 1.3 เท่านั้น

### 1.3 ใส่ token ใน GitHub
1. ใน repo บน GitHub ไปที่ **Settings → Secrets and variables → Actions**
2. กด **New repository secret** แล้วเพิ่มสองค่า
   - `CLOUDFLARE_API_TOKEN` = token จากข้อ 1.2
   - `CLOUDFLARE_ACCOUNT_ID` = Account ID จากข้อ 1.2

### 1.4 เปิด GitHub Pages
1. **Settings → Pages**
2. ที่ Source เลือก **GitHub Actions**

### 1.5 deploy server ครั้งแรก
1. เปิดไฟล์ `server/wrangler.toml` แก้ `ALLOWED_ORIGIN` เป็นที่อยู่หน้าเว็บของครู (ไม่มี `/` ปิดท้าย) เช่น
   ```toml
   ALLOWED_ORIGIN = "https://6880050027.github.io"
   ```
   ค่านี้กันไม่ให้เว็บอื่นเชื่อมต่อ server ของครู ถ้ายังเป็น `"*"` ระบบจะไม่ยอม deploy server
   แล้ว Commit และ Push
2. ไปที่แท็บ **Actions** เลือก "Deploy game server (Cloudflare)" แล้วกด **Run workflow**
3. รอจนขึ้นเครื่องหมายถูกสีเขียว แล้วเปิด log ของขั้น Deploy จะเห็นที่อยู่ server ในรูปแบบ `https://word-arena.<ชื่อของครู>.workers.dev` ให้คัดลอกเก็บไว้

### 1.6 เชื่อมหน้าเว็บกับ server
1. เปิดไฟล์ `web/config.js` แก้บรรทัด `WORKER_URL` เป็นที่อยู่จากข้อ 1.5
   ```js
   export const WORKER_URL = 'https://word-arena.<ชื่อของครู>.workers.dev';
   ```
2. Commit แล้ว Push ระบบจะ deploy หน้าเว็บให้เอง
3. ที่อยู่หน้าเว็บของครูจะอยู่ใน **Settings → Pages** เช่น `https://6880050027.github.io/word-arena/`

## ส่วนที่ 2 การใช้ในชั้นเรียน

1. เปิดหน้าเว็บบนเครื่องที่ต่อโปรเจกเตอร์ แล้วกด **Host a new game**
2. จอจะขึ้นโค้ด 6 หลักและ QR code ให้นักเรียนสแกน QR หรือเข้าหน้าเว็บแล้วกรอกโค้ด จากนั้นตั้งชื่อเล่น
3. เลือกเกม (Guess the Word หรือ Davini) และวัฒนธรรม (ทั้งห้า หรือเลือกภาษาเดียว) แล้วกด **Start round**
4. หนึ่งรอบใช้เวลา 3 นาที ครูกด **End round** เพื่อจบก่อนเวลาได้
5. เมื่อจบรอบ จอจะเฉลยคำ แสดงคำอธิบายวัฒนธรรมทั้งภาษาอังกฤษและภาษาไทย และ 5 อันดับแรก
6. กด **Next round** เพื่อเล่นเกมเดิมรอบใหม่ หรือกด **Back to lobby** เพื่อเปลี่ยนเกม

**ข้อควรรู้**
- ถ้านักเรียนตั้งชื่อไม่เหมาะสม ครูกด ✕ ข้างชื่อเพื่อนำออกจากห้องได้
- มือถือนักเรียนหลุดหรือเผลอปิดแท็บ ให้เปิดลิงก์เดิมอีกครั้ง ระบบจะคืนชื่อและคะแนนเดิมให้ แต่ต้องเป็นเบราว์เซอร์เดิมและยังไม่ได้ปิดเบราว์เซอร์ทั้งหมด
- นักเรียนที่เข้ามาระหว่างรอบจะได้เล่นตั้งแต่รอบถัดไป
- ถ้าเปิดห้องทิ้งไว้เกิน 30 นาทีโดยไม่มีใครเล่น ระบบจะปิดห้องเอง
- ระบบไม่เก็บคะแนนไว้หลังปิดห้อง และไม่เก็บข้อมูลส่วนตัวของนักเรียน

**ก่อนใช้กับนักเรียนกลุ่มใหญ่:** ควรลองกับนักเรียนหนึ่งห้องก่อน เพราะ Wi-Fi หรือไฟร์วอลล์ของโรงเรียนอาจบล็อกการเชื่อมต่อแบบ WebSocket ได้ ส่วนนี้ผู้พัฒนาทดสอบแทนไม่ได้

## ส่วนที่ 3 เพิ่มหรือแก้คำศัพท์

คำศัพท์ทั้งหมดอยู่ในไฟล์ `content/words.csv` แถวละหนึ่งคำ
1. เปิดไฟล์ด้วย Excel หรือ Google Sheets แล้วแก้หรือเพิ่มแถว ทุกคอลัมน์ต้องมีค่า
   - `clue_text` ยาวไม่เกิน 3 คำ และห้ามมีคำตอบอยู่ในคำใบ้
   - `emoji1`–`emoji3` ใส่เป็นรหัส OpenMoji เช่น `1F96C` ค้นรหัสได้ที่ openmoji.org
   - ระบบนำคำเข้าเกมเฉพาะแถวที่ `teacher_approved` เป็น `yes`
2. ให้คนที่ติดตั้ง Python ไว้แล้วรันคำสั่งต่อไปนี้ (ต้องดาวน์โหลดโมเดลภาษาราว 400 MB ในครั้งแรก)
   ```
   pip install spacy numpy wordfreq english-words
   pip install https://github.com/explosion/spacy-models/releases/download/en_core_web_lg-3.8.0/en_core_web_lg-3.8.0-py3-none-any.whl
   python tools/check_words.py
   python tools/build_content.py
   ```
3. ถ้าใส่อิโมจิรหัสใหม่ ต้องเพิ่มไฟล์ SVG ของรหัสนั้นจาก OpenMoji ไว้ใน `web/vendor/openmoji/` ด้วย
4. เปิดไฟล์ `tools/report_neighbours.md` ดูว่าคำที่อยู่ใกล้คำตอบแต่ละคำสมเหตุสมผลหรือไม่ ถ้าคำไหนดูไม่เข้าท่า ให้ใส่ `no` ในคอลัมน์ `contexto` ของคำนั้น คำนั้นจะยังใช้ในเกม Davini ได้ตามเดิม
5. Commit แล้ว Push

ข้อสำคัญ: ห้ามคัดลอกคำนิยามหรือประโยคตัวอย่างจาก Cambridge หรือ Oxford มาใส่ในคำใบ้หรือคำอธิบาย เพราะเป็นเนื้อหาที่มีลิขสิทธิ์ ให้เขียนขึ้นเองทั้งหมด

## ส่วนที่ 4 เพิ่มเกมใหม่ (สำหรับผู้เขียนโปรแกรม)

แต่ละเกมมีสามไฟล์
- `server/src/games/<id>.js` ตรรกะฝั่ง server ต้องมีฟังก์ชัน `pickContent`, `startRound`, `onGuess`, `playerView`, `publicView`, `endRound` (ดูคำอธิบายใน `server/src/games/index.js`)
- `web/games/<id>/host.js` หน้าจอครู ต้อง export `mount()` และ `renderReveal()`
- `web/games/<id>/player.js` หน้าจอนักเรียน ต้อง export `mount()`

จากนั้นเพิ่มเกมใน `list` ของ `server/src/games/index.js` และเพิ่มตัวเลือกใน `web/host.html` (`<select id="game">`) และ `NAMES` ใน `web/host.js` กับ `web/play.js`

## ข้อจำกัดที่ควรรู้
- แผนฟรีของ Cloudflare รับได้ 100,000 คำขอต่อวัน ผู้พัฒนาประมาณว่าหนึ่งรอบ 200 คนใช้ราว 600 คำขอ ตัวเลขนี้เป็นการประมาณ ผลวัดจริงจะบันทึกไว้ใน README หลังทดสอบ
- เกม Guess the Word ให้อันดับละเอียดเฉพาะ 5,000 คำที่ใกล้คำตอบที่สุด คำที่ไกลกว่านั้นจะแสดงเป็น "5000+ · Far"
- ระบบปฏิเสธคำบางกลุ่ม เช่น คำหยาบ คำเกี่ยวกับยาเสพติด อาวุธ และแอลกอฮอล์ ถ้านักเรียนพิมพ์คำเหล่านี้ จะขึ้นว่า "not in our word list"
- ระดับ CEFR ในไฟล์คำศัพท์เป็นค่าประมาณ ยังไม่ได้เทียบกับ English Vocabulary Profile
